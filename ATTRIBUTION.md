# Attribution

Goal Dashboard is an independent plugin that reuses the **design logic** of an earlier project and
embeds metadata derived from a skills repository. This file records exactly what came from where.

## 1. Design logic — miuzel/dsh-graph

- **Project:** [miuzel/dsh-graph](https://github.com/miuzel/dsh-graph) — "把工作组织成目标看板的 DeepSeek Harness (dsh) 插件"
- **Author / copyright:** Copyright © 2026 miuzel
- **License:** MIT
- **What we took — concepts only, no code:**
  - a goal is a self-contained entity: a natural-language task plus explicit, registered quality criteria;
  - **criteria precede execution** — a goal may not enter `in_progress` without criteria;
  - a hard, engine-enforced lifecycle state machine (`draft → planning → collecting → ready →
    in_progress → review → delivered`, with `blocked` returning only to its origin);
  - an **append-only event log** as the source of truth, with goal files as a readable projection;
  - a plain-text, git-friendly data directory (`<workspace>/.goal-board/`).

  This repository contains no dsh-graph source code. It is a clean re-implementation written against
  the documented DeepSeek Harness plugin contract. Where the two differ, the difference is
  deliberate and is explained in `README.md`.

- **Why it is not a fork:** the upstream browser half cannot load on the DSH desktop host. Its
  `dsh.client.inject` declares `@deepseek-ai/dsh-client-runtime`, a package that is absent from the
  desktop app's bundled package set; the entry therefore fails to activate and the host aborts the
  entire web boot. Upstream's own crash record on the desktop reads `dsh-graph: failed`
  (`crash-2026-10-02T01-33-40-602Z-web-boot.log`). This plugin avoids that failure mode by having no
  browser half at all.

  The earlier fork that briefly occupied this repository is preserved in git history
  (commits `7e8e016` … `d9b5ae0`) for reference.

## 2. Skill catalogue metadata — mattpocock/skills

- **Project:** [mattpocock/skills](https://github.com/mattpocock/skills) — "Skills for Real Engineers"
- **Author / copyright:** Copyright © 2026 Matt Pocock
- **License:** MIT
- **What we use:** derived *metadata* only — for each skill its name, category, invocation kind
  (`user` / `model`) and one-line description. This is stored in `lib/skills-catalog.json` and is
  regenerated by `scripts/gen-skills-catalog.mjs`.
- **What we do NOT vendor:** the skill bodies. Goal Dashboard never redistributes the content of any
  `SKILL.md`. Users install the skills themselves from the upstream repository.
- We also adopt the *shape* of the upstream engineering workflow
  (`grill-with-docs → to-spec → to-tickets → implement → code-review → pr`) as the
  `engineering-feature` preset.

## 3. DeepSeek Harness

DeepSeek Harness and its `@deepseek-ai/*` packages are the host platform, not part of this
repository. This plugin declares no runtime dependency on them and imports none.
